# QA Automation Coding Course — Domain Language

Browser-based interactive code sandbox for learning QA test automation and software quality engineering.

## Language

**Track**:
A dedicated learning syllabus covering a specific automation or QA discipline (e.g. Playwright, Robot Framework, API Testing, Performance Testing, DB Design/SQL, Security).
_Avoid_: Course, Topic, Subject

**Lesson**:
A discrete learning unit within a track containing theory, an editable code template, in-browser validation, hints, and a reference solution.
_Avoid_: Chapter, Lecture, Assignment

**Sandbox**:
The client-side in-browser editor and execution environment validating code without a remote server or container.
_Avoid_: Remote runner, Virtual machine, Docker container

**Validator**:
In-browser JavaScript assertion engine that evaluates the learner's code output or state against pass/fail criteria.
_Avoid_: Backend grader, CI runner

**Progress Sync**:
Exporting and importing learner progress as a JSON file via browser file APIs to move state across devices.
_Avoid_: Cloud account, Remote sync, User profile

**Code Template**:
Pre-populated starter code containing a `WRITE YOUR CODE HERE` marker that the learner edits to solve the challenge.
_Avoid_: Boilerplate, Starter repo
