A SECOND fixed fixture only raises the bar by one `if` (still beatable by a 2-branch lookup table keyed on input shape, e.g. `input.length===3 ? A : B`) — the durable fix is RANDOMIZED fixture values with the validator computing the expected output at runtime, not fixed literals. `Math`/`Math.random()` works fine in course.js's own browser runtime AND in `shared/selftest.mjs`'s vm sandbox (language builtin, not host-specific like `setTimeout`).
